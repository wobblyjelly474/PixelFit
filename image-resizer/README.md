# PixelFit

Bulk image resizing web application built using Next.js.

## Features

- Bulk image upload
- Folder upload support
- Automatic aspect ratio resizing
- White padding for portrait images
- JPEG conversion
- ZIP download
- Fast browser-based processing

## Supported Ratios

- 1:1
- 4:3
- 16:9
- 9:16

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- JSZip
- FileSaver.js

## Local Setup

```bash
npm install
npm run dev
```

## Deployment

Deployed using Vercel.
